# 基于深度学习（YOLO）的水稻病害智能识别系统

## 📌 项目简介
本项目是一个面向智慧农业领域的桌面端应用，旨在帮助农业工作者或研究人员快速、准确地识别水稻病害。系统采用 Python 开发，结合了深度学习目标分类算法与直观的图形用户界面（GUI），实现了从模型推理到业务展示的完整闭环，可直接应用于实际场景中的病害筛查。

## 🚀 核心功能
* **多源数据输入**：支持单张图片导入、文件夹批量读取、视频抽帧检测以及摄像头实时画面读取。
* **高精度病害识别**：内置基于 YOLO 训练的分类模型，可精准识别四种常见水稻病害：**白叶枯病、稻瘟病、褐斑病、枯草病**。
* **毫秒级推理**：针对本地 CPU 环境进行优化，单张图片推理耗时可低至毫秒级，并在界面上直观展示置信度与耗时。
* **表格联动追溯**：底部的识别结果表格（Treeview）支持历史记录展示。点击表格中的任意记录，左侧主界面会自动回显对应的图片和识别数据，方便对比分析。

## 🛠️ 技术栈
* **界面开发**：`Tkinter` (内置 `ttk.Treeview` 数据表格组件)
* **深度学习框架**：`Ultralytics` (YOLO 目标分类模型)
* **图像处理**：`OpenCV` (视频抽帧、色彩空间转换), `Pillow` (图片缩放与界面渲染)
* **数据处理**：`NumPy`

## 💡 工程落地亮点（开发难点与解决）
1. **中文路径兼容优化**：在开发过程中，发现部分底层图像读取库无法直接处理包含中文字符的路径。通过采用 `cv2.imdecode` 结合 `np.fromfile` 的字节流解码方式，完美解决了 Windows 环境下中文路径读取报错的问题，提升了系统的健壮性。
2. **视频抽帧策略优化**：为了避免直接逐帧检测导致界面卡顿，在视频检测模块中设计了**抽帧策略**（代码中设置为每 100 帧读取一次），在保证检测覆盖率的同时，大幅降低了计算资源消耗，保证了界面的流畅运行。
3. **GUI 交互逻辑设计**：实现了数据与界面的双向绑定，用户无需手动输入路径，通过鼠标点击即可完成图片、文件夹、视频和摄像头的切换与结果追溯。
